# Krypton Browser for Windows

**Workspaces, vertical tabs and more room for the way you browse.**

Krypton is a Windows browser built around organized tabs, flexible workspaces
and a clean interface. Built on Helium, it brings together browsing ideas
familiar to Arc and Zen Browser users.

## What Krypton offers

- **Organized browsing:** workspaces, folders and Essentials for the sites you
  want to keep close, with vertical or horizontal tabs.
- **Pages side by side:** split views for working across pages, plus Glance
  previews for a quick look at a link.
- **More space for your content:** compact and dynamic layouts that let the
  interface step out of the way.
- **A personal look:** workspace themes and Boosts for changing how individual
  sites look.
- **Everyday tools together:** downloads, history and media controls in Library.

For people exploring an Arc browser alternative on Windows, enjoying Zen
Browser's sidebar-focused browsing, or looking for a different interface built
on Helium, Krypton offers its own take on those familiar workflows.

Krypton is an independent project in active development.
